# 🌺 Iris Flower Species Predictor

An interactive Web Application built with **Streamlit** and **Scikit-Learn** that predicts the species of an Iris flower based on its sepal and petal dimensions.

---

## 🚀 Features

* **Interactive Sliders:** Easily adjust Sepal Length, Sepal Width, Petal Length, and Petal Width in real-time.
* **Instant Predictions:** Uses a pre-trained Machine Learning model to classify flowers into three species:
  * 🌸 **Setosa**
  * 🌺 **Versicolor**
  * 🌻 **Virginica**
* **User-Friendly UI:** Simple, clean, and intuitive layout built using Streamlit.

---

## 🛠️ Tech Stack

* **Language:** Python 3.x
* **Framework:** Streamlit
* **Machine Learning:** Scikit-Learn, NumPy
* **Model Serialization:** Joblib
